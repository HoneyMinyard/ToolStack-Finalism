E-Commerce Store Tool Stack

Tool Priorities & Actionable Deliverables Guide

Customer Order Journey
1

Browse Catalog

Customer views live items dynamic from Google Sheets on static site.

2

Build Cart

Customer selects variations & adds items to local browser cart.

3

Submit Request

Customer enters details in modal & clicks "Submit Order Request".

4

Auto Stock Reserve

Apps Script checks availability & locks stock to "Reserved" on Sheets.

5

Email Summary

System sends clean order breakdown (no QR code) to customer & seller.

6

DM & Payment

Customer sends Ref # in DMs; seller approves & provides payment QR.

Tool Stack Deliverables & Objectives
Tool 01

ChatGPT

AI Development & Code Generation
What Needs to be Achieved
  • Generate Frontend Codebase: Prompt and refine clean, responsive HTML, CSS, and JavaScript for the website and shopping cart modal.
  • Cart Logic Development: Write JavaScript for browser storage (localStorage) to handle item selection, quantity adjustments, and cart totals.
  • Backend Integration Snippets: Draft Google Apps Script functions to connect the website frontend to Google Sheets via API calls.
  • Responsive Styling: Design CSS layouts tailored for both mobile devices and desktop views.
Tool 02

GitHub

Code Repository & Asset Storage
What Needs to be Achieved
  • Repository Architecture: Initialize the repository with main (production build) and dev (testing/staging) branches.
  • Image Asset Storage: Create an assets/images/ directory to store and serve raw, high-resolution product photos.
  • Version Control: Test code updates safely in dev before merging changes into main.
  • Direct Image Linking: Serve direct raw content URLs to populate product photos in the Master Google Sheet catalog.
Tool 03

Cloudflare Pages

Hosting & Continuous Deployment
What Needs to be Achieved
  • GitHub Integration: Connect the repository’s main branch directly to Cloudflare Pages.
  • Automated Builds: Enable continuous deployment to automatically rebuild the live site whenever changes are merged into main.
  • Domain & Security Setup: Secure the live site on HTTPS with a custom *.pages.dev domain.
Tool 04

Google Sheets

Master Inventory & Database
What Needs to be Achieved
  • Master Inventory Schema: Set up product tables with distinct columns for Product ID, Title, Category, Price, Direct Image URL, and Stock Availability.
  • Order Log Schema: Build an automated Order Requests tab logging Timestamp, Order Reference #, Customer Details, Ordered Items, Total Cost, and Status.
  • Formula Sanitization: Keep inventory data columns free of cell formulas so Google Apps Script queries parse clean data.
Tool 05

Google Apps Script

Backend API & Automation Engine
What Needs to be Achieved
  • Web App API Deployment: Deploy a Web App endpoint script to receive POST request payloads from the site checkout modal.
  • Real-Time Inventory Audit: Check item availability in Google Sheets before accepting an order request.
  • Automated Stock Locking: Automatically switch item status to "Reserved" on the spreadsheet upon successful submission.
  • Email Notification Dispatch: Trigger automated order summary emails (containing line items, total fees, and reference numbers) to both customer and seller without attaching payment details.
Tool 06

Custom Frontend

Catalogue + Cart Interface
What Needs to be Achieved
  • Dynamic Catalog Rendering: Fetch real-time product lists from Google Sheets to render available catalog items dynamically.
  • Cart Management: Provide an intuitive shopping cart modal using localStorage to retain items during browser sessions.
  • Customer Info Capture: Collect required buyer information (Name, Shipping Address, Regional Destination, Instagram Handle) at checkout.
  • Payload Dispatch: Format cart details into a JSON payload and post it to the Google Apps Script endpoint.
Tool 07

Instagram DMs

Order Verification & Customer Hub
What Needs to be Achieved
  • Reference Cross-Checking: Receive customer order reference numbers in DMs and match them against logged Google Sheets entries.
  • Manual Order Review: Audit reserved items, delivery region, and shipping fees before approving the transaction.
  • Payment Dispatch: Send GCash / Bank Transfer QR codes directly in DM conversations once the order is verified.
  • Status Updates: Mark orders as "Paid / Processing" in Google Sheets and notify customers on fulfillment progress.
Tool 08

GCash & Bank Transfer

Payment Processing
What Needs to be Achieved
  • QR Asset Preparation: Generate official GCash and Instapay/Bank Transfer QR codes.
  • Payment Verification: Verify incoming transaction receipts submitted by buyers in Instagram DMs against account records.
  • Reconciliation: Match confirmed transactions with corresponding invoice amounts before dispatching packages.
Final Step: Once payment is validated, change the sheet status from "Reserved" to "Paid / Processing" to authorize final shipping.
